# Options Literacy Glossary

A definitions-only reference for the vocabulary of options. It explains what the terms mean so you can read and understand options discussion. It does not contain strategies, recommendations, or any suggestion to trade options.

**Not financial advice, and a specific warning.** Options can lose their entire value, and some positions can lose more than you put in. This glossary exists so you understand words, not so you trade. If you do not fully understand the risk of a position, the correct action is to not take it. Nothing here is a recommendation.

## What this is

A plain glossary. Every entry defines a term. There are no entries that tell you when to use anything, because that would be strategy and strategy is out of scope here by design.

## What is inside

- [01-the-basics.md](01-the-basics.md) defines the core building blocks: calls, puts, strike, expiration, premium, and what holding versus writing means.
- [02-moneyness-and-value.md](02-moneyness-and-value.md) defines in, at, and out of the money, plus intrinsic and extrinsic value.
- [03-the-greeks.md](03-the-greeks.md) defines delta, gamma, theta, vega, and rho as sensitivities.
- [04-mechanics-and-settlement.md](04-mechanics-and-settlement.md) defines exercise, assignment, expiration, and settlement types.
- [05-risk-vocabulary.md](05-risk-vocabulary.md) defines the words used to describe how options positions lose money.
- `GLOSSARY.md` is the full alphabetical list.

## How to use it

Look up a term when you hit it. Read `01` first if options are new to you. Stop and re-read `05` before you ever consider a real position, because the risk vocabulary is the part people skip.
